## Glass that has to survive the processor

![Xylene-resistant microscope slide labels](https://cdn.labtag.com/wp-content/uploads/XAL-67SB-use1.jpg "/media/histology-labels/XAL-67SB-use1.jpg")

Thermal-transfer slide labels resist the processor chemicals and still run on the barcode printers already in the lab. Laminate-free faces do not pick up stain color.

- Thermal-transfer slides — xylene, toluene, hexanes, alcohols, and acetone
- Stain-resistant — eosin Y, hematoxylin, and safer xylene substitutes
- Laminate-free — faces that do not pick up stain color
- Automated processors — the printers and stainers already in the lab
- HistoLAM™ — clear flap for IHC antigen retrieval and long xylene baths

ParafiTAG™ bonds to recently cooled paraffin and FFPE cassettes from −55°C to +70°C, and holds through xylene, alcohols, acetone, and MEK.

- ParafiTAG™ — recently cooled paraffin and FFPE cassettes, −55°C to +70°C
- Solvent hold — xylene, alcohols, acetone, and MEK

- ParafiGARD™ — metallic layer for metal-detector find without losing xylene resistance

## Incoming slides that already have an ID

![Histo-PinTAG microscope slide over-labeling](https://cdn.labtag.com/wp-content/uploads/AZA-559-Step3-1-scaled-1-1.jpg "/media/microscope-slide-over-labeling/AZA-559-Step3-1-scaled-1-1.jpg")

Histo-PinTAG™ covers the old 2D code with a dot and snaps off a rectangle for the new internal ID below the original label. Original case data stays visible. Coverslip thickness stays in spec.

- Histo-PinTAG™ — dot covers the old 2D; rectangle is the new internal ID
- Removable — peels clean; yellow flags the re-ID
- Original data — stays visible; coverslip thickness stays in spec
- Blackout cover-ups — replace an entire label when nothing original should show
- Clear overlays — protect or add data without hiding print
- DYMO reprints — alcohols, xylene, and cryo storage for a handful of slides

## Bottles next to the stainer
