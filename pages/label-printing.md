A lab print station is printer, media, ribbon, and software that talk to the same LIMS.

LabTAG specs kits and benchtop printers—including the Cody-3™—so sample IDs print the same way every day, with scientists on technical support. If you would rather not own a printer, LabTAG prints roll, sheet, and fanfold for you.

## Start with a kit, not leftover media

![Zebra printing kit](https://cdn.labtag.com/wp-content/uploads/Zebra-Printing-Kit.png "/media/label-printing-solutions/Zebra-Printing-Kit.png")

Kits ship printer, matched labels, ribbon, and software together. The first roll is in spec for the workflow instead of a generic office driver plus whatever media is in the drawer.

- Printer — matched to the workflow, not a leftover office driver
- Labels — first roll in spec
- Ribbon — chosen for the face and the chemicals it will see
- Scanners — handheld laser and 2D imagers, USB or RS-232
- Accessories — cables, ribbon cores, applicators, and dispensers
- Software — in the box with the kit

## Design templates versus storing samples

![Label design and barcode printing software](https://cdn.labtag.com/wp-content/uploads/2020/02/printing-labels.png "/media/label-software/printing-labels.png")

Use design software (including BarTender®) to build templates—text, barcodes, logos, and a database merge—for roll, sheet, and fanfold. That software does not store samples. LIMS, LIS, and ELN systems do.

- Design software — BarTender® templates with text, barcodes, logos, and a database merge
- Formats — roll, sheet, and fanfold
- Informatics — LIMS, LIS, and ELN store the samples
- Connected labs — LabMate, SciSure, Labguru, and other partners that already talk to LabTAG stock
